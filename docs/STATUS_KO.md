## v0.1.0 마감

문서에 명시한 텍스트·클라이언트 도구 bridge 범위를 유지하면서 마지막 안전장치 두 가지를 보완했습니다.

- 반환하는 function/custom 호출과 접수하는 결과에 같은 `MAX_TOOL_RESULTS` 한도(기본 32개)를 적용합니다. 결과를 받을 수 없는 호출 묶음을 만들지 않고, 초과한 묶음은 Codex에 호출을 전달하기 전에 실패시킵니다.
- SDK의 정상 종료 실패를 진단하고 강제 종료를 시도하며, 소유한 모든 client를 정리한 뒤에도 확인되지 않은 종료는 오류로 알립니다. 최종 정리 실패 시 서버와 전경 실행기는 비정상 종료 코드를 반환합니다. 검증기도 종료 실패 진단을 거절합니다.

이 변경에는 오프라인 경계값·HTTP/SSE·수명주기·별도 프로세스 회귀 검사가 있습니다. **v0.1.0의 실모델 행렬을 새로 실행하지 않았습니다.** 아래 36/36은 마감 보완 전 `4c7fea2` 소스의 기록이며 릴리스 소스의 결과가 아닙니다. 릴리스 CI와 과거 실모델 결과를 별도 근거로 구분합니다.

릴리스 소스는 바뀌지 않은 구현 지문 `a893f3bde92f92bfdebb7b816359047971f337dc43e9a4c03a85f0ac006a5258`에서 **단위·통합·문서 449/449**, **실제 Codex를 사용하는 오프라인 runtime 22/22**를 순차 통과했습니다. 두 검사 모두 SDK 대역을 사용하며 실모델 추론은 호출하지 않습니다.

재사용 조건은 [MIT 라이선스](../LICENSE)에 명시했습니다. 원본 실행과 동결 검증기는 checkout 밖에도 바이트가 동일한 비공개 사본으로 보존하며 공개 릴리스에는 첨부하지 않습니다. [v0.1.0 릴리스](https://github.com/junwoojeong100/openai-codex-ghcp-sdk/releases/tag/v0.1.0)를 유지보수 기준점으로 삼고, 미지원 기능과 장시간 내구성 확대는 후속으로 남깁니다.
