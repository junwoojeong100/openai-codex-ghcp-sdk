## 결과 읽기

새로 생성하는 `report.md`는 **Result → Per-model results → Cases needing attention** 순서로 읽으세요. **Complete matrix**를 펼치면 모든 케이스가 나옵니다. 케이스 링크는 기록된 증거 디렉터리로 연결되며, 링크가 없으면 해당 증거 경로가 기록되지 않은 것입니다. Markdown 화면 자체가 증거를 검증하지는 않습니다.

| 필드 또는 용어 | 의미 |
| --- | --- |
| `executionKind` | `live`는 실모델, `offline-self-test`는 SDK 대역입니다. 계획은 케이스를 실행하지 않습니다. |
| `catalogId` / `profile` | 버전별 검사 규칙과 요청 문구입니다. 다른 계약·프로필끼리 대체할 수 없습니다. |
| `passed` / `totalCases` | 전체 행렬 중 통과 수입니다. 실패·차단·미지원·시간 초과·미실행도 분모에 남습니다. |
| `fullMatrixPassed` | 실모델 필수 케이스와 실행 전체 조건을 모두 충족했습니다. 높은 통과율만으로는 부족합니다. |
| `thresholdMet` | TUI의 별도 95% 목표입니다. 조건을 충족한 전체 실행에서 69/72이며 전체 통과와 다릅니다. |
| `evidenceIntegrity: true` | 검증기가 증거와 다시 계산한 결과를 인정했습니다. 검사 대상 동작이 **통과했다는 뜻은 아닙니다.** |
| `implementationHash` / `sourceHash` | 소스 지문입니다. 일치하는 동결 소스를 사용하세요. 커밋 ID나 제3자 인증이 아닙니다. |
| 커버리지 | 소스 커버리지, 검토자 체크리스트 설계 점수 75%, 실모델 통과율은 별개입니다. 실측 제품 커버리지는 **미측정/null**입니다. |

예를 들어 안정성 **65/66**, `evidenceIntegrity: true`, `fullMatrixPassed: false`, 종료 코드 **1**은 모순이 아닙니다. **미통과 실행의 증거가 유효하다**는 뜻입니다. `--verify`는 증거를 확인할 뿐 실패한 케이스를 다시 실행하거나 통과로 바꾸지 않습니다. 행렬 러너에서 인자·증거 오류는 종료 코드 2입니다.

## 증거 재검증

| 위치 | 내용과 용도 |
| --- | --- |
| `docs/validation/` | 공개한 요약·해시·선별 진단입니다. 요약은 **전체 실행 보고서가 아닙니다.** |
| `.runtime/<run>/report.md` | 해당 러너가 제공하는 읽기용 보고서입니다. |
| `.runtime/<run>/report.json`과 `cases/` | 독립적으로 판정을 다시 계산하는 데 필요한 원본 행렬·케이스별 증거입니다. |
| `.runtime/<run>/source-snapshot/` | 안정성·TUI와 터미널·soak이 자동 저장합니다. 워크플로 호환성은 이 디렉터리를 **만들지 않으므로** 정확한 소스를 별도로 보관해야 합니다. |

원시 `.runtime` 디렉터리는 Git에서 제외하므로 **이 저장소를 clone해도 제공되지 않습니다.** 공개 JSON 요약이나 파일 해시만으로 재검증할 수는 없습니다. 원래 실행의 전체 디렉터리가 필요하며, 요약을 `--verify`에 넣거나 다른 실행의 증거로 대신하지 마세요.

원래 디렉터리와 일치하는 소스·의존성이 있다면 [워크플로 호환성](../COMPATIBILITY_TESTING_KO.md#결과-읽기), [안정성](../STABILITY_TESTING_KO.md#증거와-종료-코드), [TUI](../TUI_SCENARIOS_KO.md#과거-실행-검증과-종료-코드)의 안내를 따르세요. 검증에는 모델 호출이 없습니다. 필요한 입력이 없으면 독립적인 재계산은 불가능합니다. 새 실모델 실행은 새 디렉터리·명시적 실행·Copilot 사용량이 필요합니다. 터미널·soak 러너와 Opus 진단에는 별도 `--verify` 모드가 없습니다.
